To add or edit milestones, find the MILESTONES array near the top of the <script> block. Each milestone is an object with these fields:

  • year — The year as a string (e.g., "2011")
  • month — The month name (e.g., "March")
  • title — A short title for the milestone
  • icon — A single emoji character
  • story — A multi-sentence paragraph describing the event
  • highlight — Set to true for featured milestones (larger marker with glowing ring)

Example milestone object:

{ year: "2025", month: "June", title: "New Programme Launch", icon: "🚀", story: "Description of the milestone...", highlight: false }
